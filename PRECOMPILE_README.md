# Pre-Compiling the Stan Model

## Overview

This app supports **pre-compilation** of the Stan model to eliminate the 1-2 minute compilation delay on startup. When using the DEFAULT prior configuration, the app will automatically load a pre-compiled model from `bayesian_pos_model.rds`.

## Quick Start

### 1. Pre-compile the model

Run this command in the terminal from the project directory:

```R
R -e "source('precompile_model.R')"
```

This will:
- Build the DEFAULT Stan model configuration
- Compile it (takes 1-2 minutes, one-time cost)
- Save it as `bayesian_pos_model.rds`

### 2. Verify the pre-compiled model exists

```bash
ls -lh bayesian_pos_model.rds
```

You should see a file around 1-3 MB in size.

### 3. Run the app

```R
shiny::runApp()
```

When the app starts, you'll see:
```
Loading pre-compiled Stan model from: bayesian_pos_model.rds
✓ Pre-compiled model loaded successfully!
  This eliminates 1-2 minutes of compilation time.
  Model uses default priors: fisher_z + exponential
```

## How It Works

### Default Configuration

The pre-compiled model uses these DEFAULT settings:
- **ρ prior**: Fisher z-transform with μ_z=0.5365, σ_z=0.2173 (informative, ρ 95% ~ [0.35, 0.80])
- **τ prior**: Exponential(1) for both OS and PFS
- **μ priors**: Normal(-0.35, 1.0) for OS, Normal(-0.45, 1.0) for PFS

### Automatic Detection

The app automatically detects when you're using default settings:

**Using defaults → Pre-compiled model (instant)**
- No compilation delay
- Model loads in <1 second
- Faster startup and execution

**Using custom priors → On-demand compilation**
- Model compiles when you click "Run Stan Model"
- Takes 1-2 minutes (standard Stan compilation)
- Model is cached for reuse within session

## Benefits

| Scenario | Without Pre-compilation | With Pre-compilation |
|----------|------------------------|----------------------|
| First run (defaults) | 1-2 min compile + 30-60s sampling | <1s load + 30-60s sampling |
| Custom priors | 1-2 min compile + sampling | 1-2 min compile + sampling |
| Subsequent runs | Varies by caching | <1s load (if defaults) |

**Time savings**: ~90 seconds per app restart when using defaults

## Files

- `precompile_model.R` - Script to pre-compile the model
- `bayesian_pos_model.rds` - Pre-compiled model (generated by script)
- `global.R` - Loads pre-compiled model at startup
- `server.R` - Uses pre-compiled model when defaults detected

## Troubleshooting

### Model not loading

If you see:
```
Note: Pre-compiled model not found.
  To pre-compile the DEFAULT model for faster startup:
  Run: R -e "source('precompile_model.R')"
```

**Solution**: Run the pre-compilation script as shown above.

### Wrong version

If the model was compiled with an older version of rstan, you may need to recompile:

```R
# Remove old version
file.remove("bayesian_pos_model.rds")

# Recompile
R -e "source('precompile_model.R')"
```

### Compilation fails

If pre-compilation fails, the app will still work - it will just compile models on-demand as needed.

## Advanced: Custom Pre-compilation

If you want to pre-compile a different configuration, edit `precompile_model.R` to change the parameters before running it.

Example:
```r
default_stan_code <- build_stan_model_improved(
  prior_rho_type = "uniform",  # Changed from fisher_z
  # ... other parameters
)
```

Then update `server.R` to match your custom defaults in the `using_defaults` check.
